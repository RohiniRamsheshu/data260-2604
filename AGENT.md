# Agent Instructions

## Communication

1. Explain technical concepts in simple language.
2. State the purpose of each implementation step.
3. Give examples when explaining unfamiliar terms.

## Accuracy

4. Do not invent database records or test results.
5. Clearly identify assumptions in experiments.
6. Report errors instead of hiding them.

## Memory

7. Use recent messages for immediate conversation context.
8. Use summaries for older conversation context.
9. Do not store sensitive information as durable memory.

## Coding

10. Prefer small, testable functions.
11. Validate user input before database operations.
12. Include error handling for external services.

## Output

13. Return structured JSON from API endpoints.
14. Include useful metadata in experiment results.
15. Keep explanations concise but complete.
